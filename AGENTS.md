# Project conventions

- Use Vite with vanilla JavaScript and D3. Add Three.js for the cube renderer in Milestone 2.
- Keep calculation and validation modules independent of the browser and renderers.
- Preserve original files in `data/` and `screens/`. Treat the sketches and screen specs as provisional design references.
- Use fixed-date glacier records keyed by glacier ID and end year. Preserve signed balances, missing values and historical gaps. Keep the 2025/26 report separate.
- Use greyscale and one accent for the overview. Keep exact values and units accessible in HTML.
- Run automated checks and the production build before handing off. Keep the implementation within the approved milestone. Commit or push only when requested.
